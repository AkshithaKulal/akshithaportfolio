# Akshitha — The Series

Portfolio of **Akshitha Kulal**, AI/ML engineer, told as a series: sections are "episodes" and projects are "Originals".

**Stack:** React 18, TypeScript, Vite 6, Tailwind CSS 4, Framer Motion, Lenis.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Edit content

All text, projects, skills and links live in `src/data/portfolio.ts`. Replace `public/akshitha.jpg` and `public/resume.pdf` to change the photo and resume.

Motion effects respect `prefers-reduced-motion`.
